# examen-practico-grupo2unemi

## Descripción del proyecto

Nuestro proyecto tiene como objetivo demostrar la aplicación de los conceptos básicos de control de versiones mediante el uso de Git y GitHub.

A través de este repositorio, los integrantes del equipo trabajarán juntos en la creación, modificación y publicación de archivos, registrando los cambios realizados mediante commits.

## Objetivos
- Comprender el funcionamiento de Git y GitHub.
- Practicar los comandos básicos de Git.
- Gestionar los cambios realizados en los archivos.
- Fomentar el trabajo colaborativo mediante un repositorio público.
